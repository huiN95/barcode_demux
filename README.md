`barcode_demux` is a high-performance tool written in Rust for demultiplexing sequencing reads based on artificial barcodes (primers). It supports multiple input/output formats (FASTA, FASTQ, BAM) and utilizes multi-threading and the Myers bit-parallel string matching algorithm for efficient processing.

## Key Features

- **Multi-format Support**: Read and write sequences in FASTA, FASTQ, and BAM formats.
- **High Performance**: 
  - Implementation of the **Myers bit-parallel algorithm** for fast approximate string matching.
  - Multi-threaded processing with configurable thread counts.
  - Optimized IO handling using producer-consumer pattern.
- **Flexible Demultiplexing**:
  - Matches barcodes at both ends of the read (within a configurable search bound).
  - Handles single-end and double-end matches with optional filtering.
  - Configurable edit distance (max distance) for barcode matching.
- **Quality Filtering**: Integrated quality thresholding for FASTQ and BAM outputs.
- **Comprehensive Logging**: Detailed tracing logs and Prometheus-compatible metrics for monitoring performance and results.
- **Flexible CLI**: Supports both hyphenated (`--input-file`) and underscored (`--input_file`) argument styles.

## Installation

### Via Conda (Recommended)

Once available on Bioconda:
```bash
conda install -c bioconda barcode_demux
```

### Build from Source

```bash
git clone https://github.com/huiN95/barcode_demux.git
cd barcode_demux
git checkout v1.0.7
cargo build --release
```

The binary will be available at `target/release/barcode_demux`.

## Usage

### Basic Command

```bash
barcode_demux -i input.bam -b barcodes.fasta -o output-dir --log-folder logs
```

### CLI Arguments

Supports both `--arg-name` and `--arg_name` aliases.

| Argument | Short | Default | Description |
| :--- | :--- | :--- | :--- |
| `--input-file` | `-i` | (Required) | Path to input sequencing file (FASTA/FASTQ/BAM). |
| `--barcode` | `-b` | (Required) | Path to barcode/primer sequence file (FASTA). |
| `--output-folder` | `-o` | (Required) | Directory where demultiplexed files will be saved. |
| `--log-folder` | | (Required) | Directory where logs and metrics will be stored. |
| `--max-distance` | `-d` | `0` | Maximum edit distance allowed for barcode matching. |
| `--output-format` | | `fasta` | Output format: `fasta`, `fastq`, `bam`, `fq`, `fa`. |
| `--min-subread-len`| `-l` | `50` | Minimum length of the subread after removing barcodes. |
| `--min-q` | | `20` | Minimum average quality threshold for demultiplexed reads. |
| `--search-bound` | | `40` | Search range (in bp) at the beginning and end of each read. |
| `--threads` | | `0` | Number of CPU threads to use (0 for auto). |
| `--pipeline-version` | | `1` | Pipeline logic version (1, 2, 3, 4). |
| `--keep-barcode` | | `false` | Whether to keep the barcode in the output. |
| `--single-end-filter`| | `false` | Filter out reads that only match at one end. |

## How it Works

1. **Barcode Indexing**: The tool reads the provided barcode FASTA file and creates Myers matching patterns.
2. **Search Logic**: For each read, it searches the first and last `search-bound` base pairs.
3. **Classification**: Identifies double-matched, single-matched, or uncertain reads.
4. **Extraction**: The sequence between identified barcodes is extracted.
